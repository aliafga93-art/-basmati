# خطة إعادة هيكلة وتصميم نظام تدقيق البصمات الاحترافي (Linear / Stripe Aesthetic)

إعادة بناء الهوية البصرية وتجربة المستخدم لنظام تدقيق الحضور والبصمات الإداري، بالانتقال الكامل من المظهر النمطي إلى أسلوب المنصات السحابية العالمية الراقية (Linear & Stripe) مع اعتماد خط **المراعي (Almarai)** المؤسسي الهادئ وجدول تدقيق عالي الكثافة (High-Density Audit Grid) بدون أي زخارف مصطنعة، مع تكامل حساب أيام البصمات وتعديل نظام الـ 3 أو 5 بصمات.

---

## مراجعة المستخدم والقرارات الحاسمة

> [!IMPORTANT]
> بناءً على إجاباتك في مرحلة الاستيضاح، تم تثبيت المعايير التصميمية التالية لتطبيقها بدقة هندسية:
> - **الخط العربي المعتمد**: خط **المراعي (Almarai)** بأوزانه المتناسقة مع خط أرقام مونو (JetBrains Mono) للأوقات والتواريخ.
> - **الطابع البصري**: أسلوب **Linear & Stripe** (رماديات هندسية محايدة Zinc/Slate، حدود متناهية الدقة 1px، بطاقات مسطحة بلا تدرجات لونية مبالغ فيها، ومؤشرات دقيقة بلون أحادي أو دلالي خافت).
> - **عرض البيانات**: **جدول تدقيق عالي الكثافة (High-Density Compact Table)** بتصميم وظيفي مركز، مساحات رأسية مدروسة، ومؤشرات حضور دقيقة بدون فقاعات أو بطاقات متضخمة.

- **القرار المؤكد 1**: إدراج خط المراعي وتطبيق تباين هادئ ومريح للعين في الاستخدام المكتبي الطويل.
- **القرار المؤكد 2**: توفير محول سريع ومباشر لقاعدة البصمات (3 بصمات رسمية أو 5 بصمات اعتيادية) مع إعادة احتساب النواقص ونسب الالتزام فورياً.
- **القرار المؤكد 3**: إبراز عمود إحصائي لعدد "أيام البصمات الفعلية" لكل موظف مقابل أيام العمل المقررة.

---

## 1. النظرة العامة وجوهر المنظومة

### ماذا يقدم النظام؟
نظام تدقيق وإدارة الحضور والانصراف مصمم لأقسام الموارد البشرية والتدقيق الإداري، يتيح استيراد سجلات البصمات وتحليلها بدقة متناهية، واكتشاف فجوات الحضور سواء على نظام الـ 5 بصمات أو الـ 3 بصمات، مع حساب أيام الحضور الفعلي وتوليد محاضر التدقيق الرسمية وتصديرها بصيغة Excel عالية الجودة.

### الشريحة المستهدفة
مدققو الحضور، مسؤولو الموارد البشرية، والقيادات الإدارية التي تبحث عن نظام تقني جاد، سريع، وخالٍ تماماً من مظاهر واجهات الذكاء الاصطناعي الرديئة.

### القيمة التشغيلية
- سرعة فحص آلاف السجلات في ثوانٍ معدودة.
- التوافق الفوري مع الأوامر الإدارية المستجدة (مثل تخفيض البصمات إلى 3 أو إبقائها 5).
- سهولة اتخاذ القرار عبر جدول تدقيق مدمج يعرض أهم المؤشرات في شاشة واحدة دون تشتيت.

## 2. تجربة المستخدم والتصميم البصري (Linear / Stripe Design System)

```
┌────────────────────────────────────────────────────────────────────────┐
│  بصمتي برو  |  نظام تدقيق الحضور المؤسسي            [قاعدة: 3 بصمات ▼]  │
├────────────────────────────────────────────────────────────────────────┤
│  [رفع ملف Excel]  |  [بحث بالاسم/الرقم...]  |  [فلتر: الكل / النواقص]  │
├────────────────────────────────────────────────────────────────────────┤
│  إحصائيات فورية:  الموظفون: 24 │ أيام العمل: 22 │ الملتزمون: 92% │ الفجوات: 3 │
├────────────────────────────────────────────────────────────────────────┤
│  جدول التدقيق عالي الكثافة (High-Density Matrix)                       │
│  ┌─────┬───────────┬──────┬───────┬───────┬───────┬───────┬─────────┐  │
│  │ ت   │ الموظف    │ أيام │ ب 1   │ ب 2   │ ب 3   │ نسبة  │ إجراء   │  │
│  ├─────┼───────────┼──────┼───────┼───────┼───────┼───────┼─────────┤  │
│  │ 01  │ أحمد علي  │ 20/22│ 08:02 │ 12:15 │ 15:01 │ 96%   │ [فحص]   │  │
│  │ 02  │ سارة حسن  │ 18/22│ 08:10 │ غياب  │ 14:55 │ 78%   │ [فحص]   │  │
│  └─────┴───────────┴──────┴───────┴───────┴───────┴───────┴─────────┘  │
└────────────────────────────────────────────────────────────────────────┘
```

### الهوية البصرية ولوحة الألوان
- **الخلفيات**: أبيض نقي مع درجات Zinc الفاتحة جداً (`#fafafa` و `#ffffff`) وألواح تباين هادئة، مع خيار النمط المظلم التنفيذي السلس (Linear Dark).
- **الحدود والفواصل**: خطوط رفيعة جداً بلون خافت محكم (`border-zinc-200` في الفاتح و `border-zinc-800` في الداكن) لإنشاء هيكل معماري منضبط دون كتل بارزة.
- **الطباعة**: 
  - خط **المراعي** للنصوص والعناوين والأزرار بنسق هندسي مريح (`font-sans`).
  - خط **JetBrains Mono** للأرقام الترتيبية، أوقات البصمات، وساعات العمل بنسق جدولي ثابت (`tabular-nums`).
- **المؤشرات والشارات (Badges)**:
  - إيقاف الشارات الدائرية المتضخمة واستبدالها بنقاط ميكروية (Status Dots) مع نص رقيق بلون رمادي/زمردي/كهرماني محايد.
- **التفاعل السلس**:
  - تظليل هادئ لأسطر الجدول عند التمرير (`hover:bg-zinc-50/80`).
  - لوحة فحص جانبية تنزلق بنعومة (Drawer) لعرض شريط الورديات والأوقات المسجلة دون مغادرة جدول التدقيق الرئيسي.

## 3. القرارات الهندسية والمزايا الوظيفية

### 1. مرونة قاعدة البصمات (3 بصمات مقابل 5 بصمات)
- **الآلية**: مفتاح تحكم فوري يتيح للمدقق اختيار:
  - **نظام 5 بصمات**: (حضور صباحي، تأكيد منتصف الصباح، استراحة/صلاة، تأكيد ما بعد الظهر، انصراف).
  - **نظام 3 بصمات**: (حضور بداية الوردية، بصمة إثبات التواجد النصفية، انصراف نهاية الوردية).
- **الأثر**: يعاد فورياً تقييم كل موظف وحساب نسب الالتزام والنواقص بدقة متناهية بناءً على الأمر الإداري المطبق.

### 2. تدقيق واحتساب "أيام البصمات"
- **الآلية**: استخلاص التواريخ الفريدة التي سجّل فيها كل موظف حركة بصمة واحدة على الأقل، ومقارنتها بإجمالي أيام عمل الشهر المقررة (مثال: `21 يوم من أصل 22`).
- **العرض**: عمود مخصص في الجدول الرئيسي بنمط `أيام الحضور (النسبة)` مع تصنيف لوني هادئ.

### 3. إزالة عناصر "AI Slop"
- استبدال العبارات التسويقية الرنانة والأيقونات المتوهجة بنصوص إدارية رصينة ومصطلحات محاسبية متعارف عليها.
- التخلص من الظلال الكثيفة (Drop Shadows) والأزرار ذات التدرجات اللونية الفاقعة.

```
       ┌───────────────────┴───────────────────┐

```

### خطوات التنفيذ بعد الموافقة:
1. **تحديث ملف `index.html` و `index.css`**: تضمين خط **المراعي Almarai** بنسخه الرسمية مع إعداد متغيرات Tailwind CSS لتطابق سمة Linear/Stripe.
2. **ترقية محرك المعالجة `attendanceProcessor.ts`**:
   - إضافة خاصية `punchRuleMode: '5_punches' | '3_punches'`.
   - حساب دقيق لحقل `fingerprintDaysCount` و `expectedWorkDays`.
   - ضبط النواقص لتلائم النظامين.
3. **إعادة كتابة `App.tsx`**:
   - تطبيق واجهة Linear/Stripe الرصينة.
   - بناء جدول التدقيق المدمج عالي الكثافة مع تثبيت الترويسة (Sticky Header).
   - توفير مفتاح التبديل المباشر بين 3 و 5 بصمات مع حفظ الإعداد في الذاكرة.
   - توفير التصدير الشامل المعتمد للملفات.
4. **الفحص والتحقق الكامل**: تشغيل أدوات الفحص والتجميع والتأكد من انعدام أي أخطاء برمجية.
